КЛЮЧЕВЫЕ ОСОБЕННОСТИ
---------------------
- runsc (gVisor) — ядро Linux эмулируется через gVisor, что объясняет
  версию ядра 4.4.0 и скрытую модель CPU. Это sandbox Google для
  контейнеров с повышенной изоляцией.

- Egress proxy — весь исходящий трафик идёт через JWT-аутентифицированный
  прокси Anthropic (21.0.0.163:15004). Прокси настроен для HTTP, HTTPS,
  npm, yarn, Java, pip — все инструменты маршрутизируются через него.

- Entrypoint — CLAUDE_CODE_ENTRYPOINT=remote_mobile, сессия запущена
  с мобильного устройства.

- Claude Code версия — 2.1.42, модель Opus 4.6.

- Рабочая директория — /home/user/utils (git-репозиторий dipsx/utils).

- Git proxy — включен (CCR_TEST_GITPROXY=1), git-операции тоже идут
  через прокси.

ВЫВОД

Полноценная dev-среда в облачном sandbox-контейнере Anthropic с

предустановленных языков и инструментов.
